# Электромонтажные работы в Белорецке

Статический сайт-лендинг для бригады электромонтажников.

## Как запустить сайт на GitHub Pages (бесплатно):

1. **Создайте аккаунт на GitHub**, если его ещё нет.
2. **Создайте новый репозиторий**:
   - Нажмите кнопку "New" (Новый) в верхнем правом углу.
   - Назовите его, например, `electro-beloretsk`.
   - Выберите "Public" (Публичный).
   - Нажмите "Create repository".
3. **Загрузите файлы**:
   - В созданном репозитории нажмите ссылку "uploading an existing file".
   - Перетащите туда 4 файла: `index.html`, `style.css`, `script.js`, `README.md`.
   - Внизу нажмите зелёную кнопку "Commit changes".
4. **Включите GitHub Pages**:
   - Перейдите во вкладку "Settings" (Настройки) вашего репозитория.
   - В левом меню найдите раздел "Pages" (Страницы).
   - В разделе "Build and deployment" в пункте "Branch" выберите `main` (или `master`) и папку `/ (root)`.
   - Нажмите "Save".
5. **Готово!** Через 1-2 минуты сверху появится ссылка вида `https://ваш-ник.github.io/electro-beloretsk/`. По этой ссылке будет доступен ваш сайт.

## Что изменить под себя:
- В `index.html` замените номер телефона `+7 (900) 123-45-67` на реальный.
- Замените email на ваш рабочий.
- При желании добавьте реальные фотографии ваших работ в раздел "Процесс" или "Услуги" с помощью тега `<img>`.
